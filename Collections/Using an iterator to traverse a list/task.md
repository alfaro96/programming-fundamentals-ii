# Using an iterator to traverse a list

This example **demonstrates** how to **use** an **iterator** to **traverse** a **list** in multiple ways.

---

## What does it do?

The program **creates** a **list** of **strings and uses** a `ListIterator` to:

* **Traverse** the list **from beginning to end**.
* **Traverse** the list **in reverse**.
* **Start** iteration from a **specific index**.

**Unlike** a basic `Iterator`, a `ListIterator` **provides** additional capabilities such as **reverse traversal and positional control**.

---

## Key concepts

* An `Iterator` is used to **traverse** a list **sequentially**.
* A `ListIterator` extends this functionality by allowing **bidirectional iteration**.
* Using `list.listIterator(index)` allows **iteration** to start **from any position** in the list.
* These tools provide **flexible navigation** and are **useful** for **custom iteration logic**.
