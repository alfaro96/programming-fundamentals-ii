# Programming Fundamentals II

This repository **contains** the `JetBrains Academy`-**compatible code** for **Programming Fundamentals II**, a **second-semester course** in the **Computer Science degree program**.

---

## Course context

This course **builds upon Programming Fundamentals I**, **where students learned** procedural programming in `C`, **by transitioning** to `Java` and introducing key object-oriented principles.  
Through `Java`, **students learn to structure larger applications** and apply reusable design strategies in practical software development.

---

## About this repository

This repository **includes** all the `JetBrains Academy` **tasks and supporting files** used during the course. It **contains**:

* **Code examples** that demonstrate key concepts from each module
* **Exercises** for self-guided practice
* **Assignments** to reinforce deeper learning and integration of concepts
* `JetBrains`-**compatible** `task.md` **files and configuration**: `course-info.yaml` and `lesson-info.yaml`

> These **materials** are **designed to be opened** in `IntelliJ IDEA Edu` **or** any `JetBrains IDE` **with** the `EduTools` plugin.  
> This **repository** includes **only** the **programming components** of the course, slides and lectures are managed separately.

## Technical requirements

**To run and explore** the course **material**:

- `Java 17` or later

- `JetBrains Academy` account (optional but recommended)
