# First program in Java

This assignment **demonstrates** how to **transition** from **C to Java** by **implementing iterative** and **formulaic algorithms** within the Java development environment.

---

## What do you need to do?

**In** the provided code template for **`Sum.java`**, you will find the necessary structure to solve the following tasks. You must **complete** the **methods and logic** within this file **to** successfully **pass** the **verification tests**:

* **Iterative sum implementation**: **Implement** a **`public static` method** named **`sum1`** that **calculates** the **summation** of the **first** $ \boldsymbol{n} $ **numbers**: $ sum1(n) = \sum_{i = 0}^{n} i $. **Initialize** a **variable** to $ \boldsymbol{0} $ and **use** a **`for` loop** to **accumulate** the **values** from $ \boldsymbol{0} $ **to** $ \boldsymbol{n} $.
* **Formulaic sum implementation**: **Implement** a **second `public static` method** named **`sum2`** using a **mathematical shortcut**. **Calculate** the **sum** using the **arithmetic progression formula**: $ sum2(n) = \frac{n(n + 1)}{2} $.
* **Verification and testing**: **Implement** the **logic** within the **`main` method** to **verify** your **functions**. You must **call** both **`sum1`** and **`sum2`** and **display** the **results** to the **console**. **Call** the **`sum1` method** with the **input value 11** to expect an **output** of **66**.
* **Automation of the verification process**: **Modify** the **testing loop** so the **program provides** a **direct `boolean` response** (**`true`** or **`false`**) for **each input**. **Use** the following **array of values**: **`{3, 4, 13, 21, 67, 102, 155, 365, 1007}`**.
* **Documentation**: **Generate** the **technical documentation** and **verify** the **`index.html`**.

---

## Key concepts

* **Console output** is **performed** using **`System.out.println`**, which **serves** as the **Java equivalent** to **`printf`** in C.
* **Efficiency in implementation** allows **writing** certain **functions**, like the **formulaic sum**, using only **one or two lines** of code.
* **Automated verification eliminates** the **need** for **manual inspection** by **comparing values** using **equality operators**.
* **Javadoc comments** (**`/** */`**) are **used** to **generate professional** HTML **documentation** listing all class details and parameters.
