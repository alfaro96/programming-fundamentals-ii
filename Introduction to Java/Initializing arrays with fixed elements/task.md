# Initializing arrays with fixed elements

This example **demonstrates** the **most concise way** to **declare and populate** an **array** with a **specific set of values** using short-hand initialization.

---

## What does it do?

The program `Initialization` **defines** a **collection** of **integers** to show how to **set up** an **array**:

* It **creates** an **integer array** by **providing** a comma-separated list of values inside **curly braces**.
* The program **leverages** the **compiler's ability** to **automatically determine** the **array size** based on the number of elements provided.
* It **accesses** the `length` **property** to check the **total capacity** of the **array** at runtime.
* The code **executes** a **loop** that **traverses** the **entire structure** from the first to the last element.
* It **prints each** stored **value** to the console to **confirm** the **data** was **initialized correctly**.

---

## Key concepts

* **Short-hand initialization** allows you to **declare** and **fill** an **array** in a single, readable line of code.
* **Curly braces** `{}` **serve as** the **container** for the **elements** that the **array** will hold from the moment of its creation.
* **Size inference means** the **compiler counts** the **elements** in the list **to set** the **fixed length** of the **array**.
* The **length property** remains **constant throughout** the **life** of the **array** and reflects the number of items defined during initialization.
* **Zero-based indexing** is used to **reach each item**, where the first element is always located at position `0`.
