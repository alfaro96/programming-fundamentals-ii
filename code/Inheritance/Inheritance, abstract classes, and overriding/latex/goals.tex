The \textbf{main focus} of this laboratory assignment is to \textbf{transition} from \textbf{class diagrams} to \textbf{functional classes} using abstraction and inheritance. You will \textbf{develop} the skills necessary to define \textbf{hierarchical object structures}, \textbf{implement specific behaviors}, and \textbf{manage arrays of objects} using the principles of object-oriented programming. \\

By the \textbf{end} of this \textbf{session}, \textbf{you will} be able to:

\begin{itemize}

    \item \textbf{Translate class diagrams} into \textbf{classes} with appropriate attributes, visibilities, and methods.

    \item \textbf{Use inheritance and abstract classes} to handle shared concepts between related families.

    \item \textbf{Override methods} to re-implement parent behaviors in child classes.

    \item \textbf{Manage object arrays}, including dynamic resizing (doubling size) and array compaction.

\end{itemize}
