In this laboratory assignment you'll move from a mathematical concept to a Java class that represents it. The main focus is on \textbf{defining the structure of an object} and \textbf{implementing its behavior} with methods. \\

By the end of this session, you will be able to:

\begin{itemize}

    \item Turn a real-world concept into a Java class with the right attributes and methods.

    \item Write several constructors for the same class, overloaded with different parameters.

    \item Write methods that work on the attributes of an object and return new objects.

    \item Overload a method so that it accepts different types of arguments.

    \item Document a class with Javadoc comments and generate its documentation.

\end{itemize}
