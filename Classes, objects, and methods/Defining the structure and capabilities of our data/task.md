# Defining the structure and capabilities of our data

This example demonstrates how to **create** a **blueprint** for an object by **declaring** a **class** and its **associated fields** to represent complex data.

---

## What does it do?

The program **`Player` defines** the **fundamental template** for a **new data type** designed to store athlete information:

* The **class name** is declared as **`Player`**, which **establishes** the identifier for this specific **blueprint** in the project.
* It **defines** the **internal state** of the object by **listing** three **member variables**: **`name`**, **`age`**, and **`nationality`**.
* The code **specifies** the **appropriate data types** for each attribute, using **`String`** for textual information and **`int`** for numerical values.
---

## Key concepts

* A **class** acts as a **logical template** or "mold" used to create individual objects with the same structure.
* **Fields** (also known as **attributes** or **instance variables**) are used to **store** the **data** that belongs to the class.
* **Class members** are **organized** within curly braces **`{}`** which **form** the **body** of the **class definition**.
