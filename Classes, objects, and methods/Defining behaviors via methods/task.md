# Defining behaviors via methods

This example **demonstrates** the complete **spectrum** of **object interactions** by implementing methods that perform actions, receive data, and return calculated results.

---

## What does it do?

The program **enhances** the **`Player`** class by **providing** a **variety** of public **behaviors** that the **`Main`** class will **exercise** and **validate**:

* The **`Player`** class **includes** **three** distinct **behaviors**: a **simple action** (**`celebrate`**), an **interactive task** (**`train`**), and a **data processor** (**`calculateYearsToAge`**).
* The **`Main`** program **interacts with** the **object** by assigning values to its fields and **triggering** its **different capabilities**.
* It **exercises** the object by **performing correct calls** and **documenting** the specific **reasons** why certain **invocations fail**.

---

## Key concepts

* **Method signature**: The **unique combination** of the method's **name** and its **list of parameters** that **identifies it** within the class.
* **Return values**: The **data type specified before** the **method name** that **determines** what **information** is **sent back** to the caller **using** the **`return`** keyword.
* **Argument matching**: The strict **requirement** that the **values** provided **during** a **call** must **match** the exact **number**, **type**, and **order** of the **parameters**.
