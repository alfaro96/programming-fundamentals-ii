# Divide by zero with `try` and `catch`

This example **demonstrates** how to **handle exceptions** using a `try` and `catch` block.

---

## What does it do?

The code **attempts** to **divide by zero**, which would normally cause an `ArithmeticException`. **Instead of crashing**, the **exception** is **caught and handled** gracefully **by printing a message**. The program then continues running.

---

## Key concepts

* The `try` block **wraps code** that might **throw** an **exception**.
* The `catch` block **handles** the **exception** if it occurs.
* This **example** specifically **handles** an `ArithmeticException`, which is an **unchecked exception**.
* After the exception is handled, the program continues execution.
